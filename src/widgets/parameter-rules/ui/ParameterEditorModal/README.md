## Временный флаг управления правилами

Внутри компонента `ui/ParameterEditorModal/ParameterRulesFeature.tsx` переключить `parameterRulesEnabled`:

- `false` (по умолчанию) — в редакторе доступны значение по умолчанию и его сохранение; вместо поиска, добавления и списка правил показан блок «Управление правилами в разработке». Удаление всех правил и восстановление удалённых правил также скрыты.
- `true` — полный текущий интерфейс управления правилами.

Флаг меняется в исходниках: dev-сервер подхватит изменение, для production нужна пересборка.
Существующие правила сохраняются при изменении значения по умолчанию.

Когда ограничение больше не нужно, убрать все три обёртки `<ParameterRulesFeature>`
из `ParameterEditorModal.tsx` и `ParameterEditorForm.tsx`, оставив их содержимое.
Удалить `fallback` с информационным блоком, импорты обёртки и неиспользуемый импорт `Alert`
из формы. Затем удалить `ui/ParameterEditorModal/ParameterRulesFeature.tsx`
и этот раздел инструкции.
